# 配对记录局部审计（partial scope）

本记录只覆盖已同步完成的 pairs-f16-v1、pairs-wn-v1、pairs-ws-v1、pairs-reverse-v1：共 **51 次新执行，全部 validated_success，51 份独立完整值 oracle，零 reference**。它不宣称 ordinary、cold pairs、diagnostic 或最终实验矩阵已经完成或通过整体审计。没有 SSH、运行实验、重扫数据集或修改原始记录。

本地逐项核对 plan、freeze、每格 result/metrics/cell/spec/initial-snapshot、producer.jsonl、execute/validate resources、execute-memory.jsonl、cache 观察、events 和 gates。四个 plan 的 freeze SHA 与冻结 harness 内容一致；每格源文件与二进制内容身份、实际 module/extension 路径、Python/PyArrow、validator 身份、fixture 全文件 hash 集合、variant environment、输入/写模式和资源合同均匹配记录。这里比较的是冻结记录中的内容身份，没有重新读取远端源码、扩展或 fixture 文件本体。

四份 gate 均 planned=completed、complete=true、candidate_passed=true，并与计划集合、实际结果和 started/completed 事件一致。51 个 producer 日志共 870 个 batch、27,002,175 行，逐条聚合与 result 一致且每格完整；oracle 覆盖合计 1,218 个用户字段 hash，字段集合、行数、预期 action counts、API stats 和提交版本符合 fixture 语义。逐字段值检查由原独立 U worker 完成，本次只核对其报告及执行身份。

102 个执行/验证 cgroup 路径各自唯一，均从空进程组开始，8 GiB memory.max、swap.max=0、无 timeout/OOM/cleanup_error；worker 命令、checkout、独立 TMPDIR 与冻结配置一致。execute 的 RSS、cgroup peak 和临时文件峰值均从原始采样或控制文件重算匹配。F16/Wn/Ws 配置 pool 为 1 GiB，R_admission 为 256 MiB；所有格均 reader、hot、rewrite_rows，retry/use_index 等行为沿冻结 harness。独立 validator 配置 pool 为 1 GiB。

API 计时与原始 metrics 一致；reader 的 input_materialization_seconds 均为 0，input_and_api_seconds 等于 merge_seconds。全部 51 个样本均保留，包括较慢的 block；没有剔除、替换或截尾。每个比较先在同一 block 内计算 numerator/denominator，再对三项比率取中位数。18 项预登记比较的 54 个比率与 summary 及独立提取结果一致，未使用独立耗时中位数相除。
